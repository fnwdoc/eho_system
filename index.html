1. Estrutura Single-File & Cloud Sync

O SEQLIST MÃE roda de forma autônoma em um único arquivo index.html. Todos os dados (clientes, gestores, projetos e biblioteca de processos) são mantidos em localStorage e sincronizados automaticamente via POST com a API Google Apps Script:

API Endpoint: https://script.google.com/macros/s/.../exec
Ações: "backup" (salvar nuvem) | "load" (carregar nuvem) | "enviarEmail" (notificações)

Ao exportar o HTML Master, os dados vigentes são embutidos dentro da tag <script id="seqlist-data">, tornando o arquivo 100% funcional mesmo offline.

2. Guia de Exportação & Importação (Master Admin)

  • ⬇ HTML Export (Botão Roxo no Rodapé): Gera uma versão standalone inteira do sistema com todos os dados atuais embutidos. Ideal para distribuir para clientes ou parceiros licenciados.
  • ⬇ JSON Export (Botão no Rodapé ou Card do Cliente �):
    • No painel master: Exporta o backup de dados brutos de todo o sistema.
    • No card do cliente (botão �): Exporta o arquivo individual de acesso do cliente para envio via WhatsApp ou E-mail.
  • ⬆ JSON Import: Permite importar chaves digitais de clientes ou backups inteiros para atualizar a base local e sincronizar com a nuvem.

3. Trava de Rota & Níveis de Acesso

  • Master Admin (senha fnw2025): Acesso irrestrito a todos os gestores, clientes, exportação HTML e chave master.
  • Gestor Secundário (ex: demo2025): Enxerga e gerencia exclusivamente os clientes cadastrados sob o seu gestorId.
  • Cliente (E-mail ou Código CLI-XXXX): Acessa apenas os seus projetos e atividades.
  • Guarda de Segurança (navegar): Se um visitante não autenticado tentar acessar rotas internas (admin, hub-cliente, etc.), o sistema interrompe e redireciona forçadamente para a tela de login.

4. Motor White-Label & Personalização de Marca

Como Master Admin, você pode personalizar totalmente a experiência visual:

  • Logotipo em Imagem ou Texto: Escolha entre a URL da imagem (com máscara de cor automática .logo-tinted) ou Texto estilizado com Google Fonts (Outfit, Inter, DM Serif, Playfair, Cinzel, etc.).
  • Cor Hexadecimal Personalizada (#HEX): Digite ou selecione qualquer cor hexadecimal. O sistema calcula a luminância WCAG automaticamente para garantir 100% de autocontraste e legibilidade em textos e botões!
  • Dicionário de Termos: Altere os nomes das entidades para atender diferentes nichos (ex: Unidade, Campanha, Roteiro, SOP).
